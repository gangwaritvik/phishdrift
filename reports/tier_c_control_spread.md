## Reading

- Permuting the test labels instead gives mean 0.5 and the SD of the formula above, so ties, the AUC code and the test size are not the cause.
- The spread comes from the model's noise being a function of the features, while the real phishing rows differ from benign ones in many correlated features at once. Whichever way the noise leans in that region sets the AUC for the whole split.
- If that is right, a simpler (smoother) control model should spread more, not less. Compare the rows of the first table.
- Not tested here: whether the mean below 0.5 is a real bias or chance (the mean's standard error is wide because the splits share the same rows).
