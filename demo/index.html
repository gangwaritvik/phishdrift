What this checks. The same address checks as the extension, with the same code and model files: the allowlist, the blocklist (when built on this machine), the on-device address model and the brand look-alike rules. It does not open the page, so the page model, the login-form checks and the backend's domain checks are not applied here; in the browser the extension also reads the page and can raise (or, on pages without login fields, lower) this verdict.
